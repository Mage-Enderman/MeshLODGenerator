Install via VRChat Creator Companion

➕ Add to VCC

Clicking the button will open VCC and prompt you to add this repository.

Manual Installation Steps:

  1. Open the VRChat Creator Companion.
  2. Go to Settings > Packages > Installed Repositories.
  3. Click Add Repository.
  4. Paste the repository URL copied above and click Add.
  5. Confirm with I Understand, Add Repository.
  6. Open your avatar or world project in VCC and click Add next to Mesh LOD Generator.

Mesh LOD Generator

v1.0.0

com.mageenderman.meshlodgenerator • Requires Unity 2022.3+

A standalone, non-destructive mesh LOD generator with bilateral symmetry, per-material decimation, occlusion culling, texture atlasing, and native binary FBX/GLB exporters.

  • Universal Support: Works on static meshes and skinned humanoids/creatures with zero external dependencies.
  • Bilateral Symmetry: Perfect left/right mirrored topology with centerline constraints.
  • Watertight Seam Locking: Multi-material separation with zero mesh cracking or tearing.
  • Occlusion Culling: Raycast interior culling strips hidden geometry under clothing.
  • Texture Atlasing & Baking: Multi-pass orthographic texture baking with AO and seam dilation.
  • Zero Dependencies: Built-in binary FBX & GLB exporters—no FBX SDK or external plugins required.
